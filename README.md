# Kylie's — Cold-Blended Fruit Smoothies

A high-craft, mobile-first animated storefront for **Kylie's Smoothies**, featuring multi-depth studio photography, explosive berry fly-out choreography, GSAP ScrollTrigger + Lenis smooth scroll animations, interactive flavor switching, a custom 6-pack box builder, and a working slide-over cart.

## Tech Stack
- **React 19 + TypeScript + Vite 6 + Tailwind CSS v4**
- **GSAP + ScrollTrigger** & **Lenis** smooth scrolling
- **Cloudflare Workers Static Assets** (`wrangler.jsonc`)

## Local Development
```bash
npm install
npm run dev
```

## Build & Deploy to Cloudflare Workers
```bash
npm run build
npx wrangler deploy
```
